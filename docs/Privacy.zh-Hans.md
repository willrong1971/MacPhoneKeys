# 手机键盘隐私政策

生效日期：2026-10-30。作者：九福爸爸 9fbaba。

手机键盘在你主动开启手机输入、且 App 自身获得键盘焦点时，将硬件键盘按键通过系统蓝牙发送到连接的 iPhone。它不记录输入文字，不读取 Apple 账户、通讯录或剪贴板，也不把按键发送到开发者服务器。它不包含广告、统计 SDK 或跟踪功能。

App 使用蓝牙权限提供键盘服务。全局快捷键只用于开始或停止输入；App 不申请辅助功能或输入监控权限。配对与加密由操作系统处理，配对确认由你完成。

界面偏好和连接诊断保存在本机应用数据目录。连接日志包含状态、错误和聚合计数；系统错误详情或旧连接诊断可能包含设备名称。日志不会自动上传。

只有你点击导出并选择保存位置时，App 才生成诊断报告。导出内容使用固定字段白名单，仅包含系统与 App 版本、连接状态和事件摘要，不包含原始日志、设备名称、蓝牙地址、设备标识、文件路径或输入内容。App 不会自动发送报告；是否向开发者提供报告由你决定。

App 没有账户系统。退出并卸载 App 后，可以自行删除其本机应用数据。系统管理的蓝牙配对记录保留在操作系统中，可在系统蓝牙设置中管理。经你导出的报告保留在你选择的位置。

隐私问题和支持请求可通过本项目的 [GitHub Issues](https://github.com/willrong1971/MacPhoneKeys/issues) 提交。该页面公开可见，请不要附上私人输入内容、账户信息或未经检查的原始日志。

若未来增加数据上传、账号或第三方服务，会在相应版本中更新本政策和权限说明。
