# MacPhoneKeys privacy policy

Effective date: October 30, 2026. Author: 九福爸爸 9fbaba.

When you enable phone input and the app has keyboard focus, MacPhoneKeys relays hardware key presses to the connected iPhone through system Bluetooth. It does not record typed text, read Apple account information, contacts or the clipboard, or send key presses to a developer server. It contains no advertising, analytics SDK or tracking features.

Bluetooth permission is used to provide the keyboard service. The global shortcut only starts or stops input. The app does not request Accessibility or Input Monitoring access. The operating system manages pairing and encryption, and you confirm pairing prompts.

Preferences and connection diagnostics stay in the local app data directory. Connection logs contain state changes, errors and aggregate counters; system error details or older connection diagnostics may contain device names. Logs are not uploaded automatically.

A diagnostic report is created only when you choose Export and select a save location. Reports use a fixed allowlist containing app and OS versions, connection state and event summaries. They exclude raw log messages, device names, Bluetooth addresses, device identifiers, file paths and input content. The app does not send the report. You decide whether to share it with the developer.

There is no app account. After quitting and uninstalling the app, you can remove its local app data. The operating system retains Bluetooth pairing records, which you can manage in its Bluetooth settings. Reports you exported remain at the locations you selected.

For privacy questions or support, use the project's [GitHub Issues](https://github.com/willrong1971/MacPhoneKeys/issues). Issues are public. Do not include private input, account information or unchecked raw logs.

If a future version introduces uploads, accounts or third-party services, its policy and permission disclosures will be updated accordingly.
