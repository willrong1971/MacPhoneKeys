手机键盘 / MacPhoneKeys 0.4.0 (6) 源码

需要完整 Xcode 或支持本项目 API 的 Xcode 命令行工具。

构建 Universal App（arm64 + x86_64，最低 macOS 12.0）：
  zsh build.sh
输出路径固定为 build/手机键盘.app，不随界面语言变化。

菜单栏界面：
默认常驻菜单栏，不占 Dock，也不自动打开完整设置窗口。左键点击“手机键盘”的菜单栏图标，或按全局 Control + Option + K，切换手机输入；实心图标表示正在向 iPhone 输入，灰色轮廓表示本机输入。
右键菜单提供“开始手机输入”／“停止手机输入”、“完整设置…”、帮助和退出；完整设置保留配对、诊断、日志与测试等全部功能。简短输入提示面板只在捕获期间出现；按 Esc、再次点击图标或失焦时停止输入并尝试释放按键。快捷键被占用时会提示冲突，仍可使用图标和菜单。
完整设置中的“开始输入”按钮同样打开简短输入面板；原有输入区仍可点击并在其中捕获按键。仅主动开启捕获，且输入提示面板或完整设置的输入区获得焦点时接收要转发的按键。

本次 0.4.0 (6) 新界面仅在本地预览和离线回归范围内验证，尚未进行新版手机端输入实测。现有 0.2.0 安装版保持不动，旧版手机输入成功记录不能代替新版验证。

隔离预览：
  python3 scripts/make-localization-previews.py build/手机键盘.app
预览副本在 build/localization-previews/，使用独立身份、临时日志目录和 PreviewKeyboardTransport，不启动任何蓝牙管理器，不发送手机。可测试界面、焦点、全局快捷键、图标和本地按键接收计数；仅供界面和本地按键路由验证，不能验证 iPhone 文字显示，也不作为安装版分发。

界面语言：
采用标准 macOS Bundle 语言资源 en、zh-Hans、zh-Hant，提供英文、简体中文和繁体中文。系统从 Mac 的首选语言中选择本 App 支持的语言，没有匹配时使用英文。中文名称为“手机键盘”，英文名称为 MacPhoneKeys。
更改系统首选语言后，需要完全退出并重新打开 App；如 macOS 提供 App 专用语言设置，也可单独选择本 App 的语言。运行中的界面不会即时切换。此设置与 iPhone 的输入法和硬件键盘布局无关。

制作带 Applications 快捷方式的 DMG：
  zsh package.sh
默认输出为 build/手机键盘-0.4.0-通用版.dmg。

也可以为已有 App 打包：
  zsh package.sh /绝对路径/手机键盘-0.4.0-通用版.dmg /绝对路径/手机键盘.app

版本信息为 0.4.0，构建号为 6。以后调整版本时，请同步维护 Resources/Info.plist 与 package.sh 的版本检查。

签名：
默认使用 ad-hoc 签名，仅适合开发检查。可以设置 MACPHONEKEYS_SIGN_IDENTITY 为钥匙串中已有证书的完整名称，再运行上述脚本。
Apple Development 证书不是 Developer ID 发行证书。脚本不会创建证书、上传 App 或自动提交公证。正式下载发行需要已有 Developer ID Application 证书与 Apple 公证凭据。

重建图标：
  swift scripts/generate-icon.swift
图标脚本的输出位置参见脚本参数说明；已附 AppIcon.icns 和所有尺寸的源 PNG。

本项目保留了传统蓝牙诊断后端，但默认使用旧版已有实机成功记录的 BLE 路径。
在菜单栏图标的右键菜单中打开完整设置，可访问配对、诊断和测试；默认 BLE 工作流程无需切换到传统蓝牙。

离线检查：
  zsh scripts/check.sh
各项检查的编译命令由该脚本维护。检查覆盖键码映射、BLE 队列顺序与取消行为，以及传统蓝牙 SDP 数据；不会启动 App、连接手机或操作蓝牙，不能替代蓝牙配对、手机实际显示文字和重连的实机验证。
