English: Installation-and-Usage.en.txt

把 Mac 键盘通过蓝牙连接到 iPhone。两台设备的 Apple ID 可以不同，无需更换；iPhone 无需安装 App。

默认常驻菜单栏，不占 Dock。左键点击“手机键盘”的菜单栏图标，或按 Control + Option + K，切换手机输入。真正取得输入焦点后图标才变实心，表示正在向 iPhone 输入；灰色轮廓表示本机输入。图标状态不代表手机已显示文字。

安装
1. 打开“手机键盘-0.4.1-通用版.dmg”。
2. 把“手机键盘”拖到“Applications（应用程序）”。
3. 在“应用程序”里打开“手机键盘”，允许蓝牙访问。
4. 安装完成后，可以推出磁盘映像。

0.4.1 (7) 修复关闭完整设置后启动输入时的异步激活与焦点问题，当前仍在进行本地预览和离线检查，尚未完成本版本手机端输入实测。

界面语言
App 提供简体中文、繁体中文和英文，使用标准 macOS Bundle 语言资源 en、zh-Hans、zh-Hant。系统会从 Mac 的首选语言中选择 App 支持的语言；没有匹配语言时使用英文。中文名称为“手机键盘”，英文名称为 MacPhoneKeys；构建文件路径仍为 build/手机键盘.app。
可以调整 Mac 的首选语言；如系统提供，也可在“系统设置 → 通用 → 语言与地区 → 应用程序”中为本 App 选择专用语言。更改后请完全退出并重新打开 App，运行中的界面不会即时切换。不同 macOS 版本的设置位置可能不同。
界面语言与 iPhone 的输入法、硬件键盘布局分别设置。

首次打开与签名
从本项目源码自行构建时，默认使用 ad-hoc 临时签名，不需要开发者证书，也不会自动提交 Apple 公证。历史本机测试包曾使用 Apple Development 开发证书签名；它同样不是经过公证的发行包。
在其他 Mac 上，系统可能阻止直接打开。请查看 macOS“系统设置 → 隐私与安全性”中本应用的“仍要打开”选项；旧版 macOS 对应“系统偏好设置 → 安全性与隐私”。由使用者仅对本应用决定是否允许打开，无需关闭全局安全保护。
若希望作为免手动放行的正式下载版发行，需要另行使用 Developer ID Application 证书签名并提交 Apple 公证。

连接与打字
1. App 启动后会自动开启键盘服务，菜单栏出现“手机键盘”的图标；默认不打开完整设置窗口。
2. iPhone 打开“设置 → 蓝牙”，选择这台 Mac 的名称，并核对配对码。手机通常显示 Mac 的系统名称，而不是 App 名称。
3. 在 iPhone 的备忘录等 App 中点一下文字输入位置，确认光标闪烁。
4. 连接就绪后，左键点击菜单栏图标，或按 Control + Option + K。等待简短输入面板取得焦点、图标变实心后，再用 Mac 键盘打字。
5. 按 Esc、再次点击图标，或切到其他 Mac 窗口，停止输入并尝试释放按键。

菜单栏与完整设置
右键点击图标可打开菜单，提供“开始手机输入”／“停止手机输入”、“完整设置…”、帮助与退出。完整设置中保留配对、诊断、连接记录、发送英文测试串和切换手机输入法等功能。
完整设置的“开始输入”按钮也会打开简短输入面板；也可直接点击原有输入区，在该输入区内捕获按键。
平时可以关闭完整设置，再从其他 Mac App 按快捷键或点击图标控制手机输入。0.4.1 会等待本 App 激活和输入面板取得焦点后才捕获；取消或失焦后，迟到的激活事件不会重新开启输入。
输入提示面板只在捕获期间出现；失去焦点会自动停止输入。默认全局快捷键是 Control + Option + K，如被其他程序占用会提示冲突，仍可使用图标和右键菜单。

中文
使用 iPhone 的硬件键盘输入法组词、选字。完整设置中的“切换手机输入法”按钮发送 Control + Space；之后重新点击菜单栏图标或按全局快捷键开始输入。Mac 上已经组好的中文不会直接传过去。

兼容范围与验证
通用二进制包含 Apple 芯片 arm64 和 Intel x86_64 两种架构，最低系统目标为 macOS 12.0，需 Mac 蓝牙支持低功耗外设模式。
此前 0.2.0 在本机 macOS 26.6.2 已实际验证：iPhone 保持加密键盘连接，完整显示固定测试串 mac keyboard test 123；用户使用 Mac 实际键盘手动输入 abc123，也完整显示。用户随后确认 0.4.0 也完整输入了 abc123，但那次没有严格覆盖关闭完整设置后从其他 Mac App 启动输入的情景，之后发现了该情景下的焦点问题。0.4.1 尚未完成手机端实测。
其他 Mac、macOS 12–15、其他 iPhone、中文输入及睡眠后重连尚未逐机实测，无法承诺所有历史型号都能作为蓝牙键盘使用。通用架构编译通过与蓝牙实机可用是两项不同的验证。

范围与记录
仅在主动开启捕获，且输入提示面板或完整设置的输入区获得焦点时接收要转发的按键。全局快捷键用于切换捕获状态。App 不申请辅助功能或输入监控权限，不读取 Apple 账户、剪贴板或通讯录，不经过 iCloud 或网络。
“已接收按键”包括本地等待发送的报告；以手机实际显示为准。停止输入会清理尚未交给系统的报告，并尝试释放按键；已交给系统蓝牙栈的字符无法撤回。
电量服务固定报告 100%，不是 Mac 的实际电量；设备厂商字段为实验占位值。
连接日志只记录连接事件、错误和计数，不记录输入内容。路径：
~/Library/Application Support/MacPhoneKeys/

卸载
先在菜单栏图标的右键菜单中退出 App，再将“应用程序”里的“手机键盘”移到废纸篓。系统的蓝牙配对记录会保留；需要时可在手机蓝牙设置里单独忽略这台 Mac。
